# Migration cutover card

- Maintenance window is named, and a rollback DID is named.
- One DNIS moves. The campaign that owns it is running.
- A test call hits the skill you chose, not Default, unless Default was the plan.
- Recording notice and retention clock are known for that call.
- Abandon posture is the campaign field, not a number invented in a slide.
- Someone can stop the cut if 911, recording, or the test call fails.
- Skills exist, and the right users are in them.
- User profiles exist before user accounts.
- Contact fields, lists, and dispositions exist before the outbound campaign.
- Inbound and autodial have prompts and an IVR script.
- One campaign profile is assigned. ANI lives there, not in a rumor.
- Reporting role can open a standard report on a test call.
- DNC list and IVR DNC behavior are named.
- 911 locations match the rooms people sit in.
