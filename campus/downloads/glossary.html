Glossary starter

Five9 Lab study card. Numbers and names point at the sources. This is not a Five9 document.

  1. Domain: The VCC tenant. Skills, users, lists, and campaigns stay inside it.
  2. Skill group: Agents or supervisors who can take a campaign's work. A user and a campaign can have more than one.
  3. User profile: The permission template for a person. Not a campaign profile.
  4. Campaign profile: Overrides defaults such as ANI. One profile is assigned to a campaign. The same profile can be reused.
  5. Campaign: Inbound, outbound, or autodial. Blended is staffing language, not a fourth type.
  6. DNIS: The number an inbound campaign answers. A stopped campaign does not answer.
  7. Disposition: The outcome code on a call. Final disposition stops the other numbers on that record for the campaign.
  8. List penetration: The default list walk: first number on every record, then the next number.
  9. Vertical dialing: Finishes the numbers on one record before moving on. Community notes say the compass wording is easy to misread.
  10. Preview: The agent sees CRM history before the dial.
  11. Progressive: The outbound page describes one customer call per available agent. The dialer page also says adaptive pace. Quote the page you mean.
  12. Power: A configured number of calls per agent, with an abandon throttle.
  13. Predictive: Algorithmic pacing. Product guidance talks about teams larger than about ten agents.
  14. Manual touch: No automatic dial. TCPA manual touch adds typing, blocks paste, and enables Dial on a match.
  15. Max Abandoned Call Percentage: A campaign field with a warning if you change it. This lab does not state a numeric default.
  16. IVR module: A named block in the IVR Administrator's Guide, such as Menu, Play, If/Else, or Skill Transfer.
  17. Skill Transfer: Sends the call toward one or more skills. No skill selected means the Default queue in the community write-up.
  18. Default queue: Where a Skill Transfer with no skill goes, per the community article.
