Ports and protocols

Five9 Lab study card. Numbers and names point at the sources. This is not a Five9 document.

  1. 80 TCP Outbound: HTTP for sign-in, reporting, and support pages.
  2. 443 TCP Outbound: HTTPS for sign-in, reporting, and support.
  3. 1024-65535 UDP Outbound: RTP between Five9 applications. Without a stateful firewall, allow the return path. WebRTC also sends STUN on these ports.
  4. 2200-2300 TCP Outbound: Encrypted Java RMI on the community softphone table. Java Agent and Supervisor desktops left the customer portal after 1 August 2026. Confirm whether your site still launches Java admin.
  5. 5060-5067 UDP Outbound: SIP for the agent application.
  6. 5080 UDP Outbound: SIP signaling on the Five9 SIP proxy.
  7. 5081 TCP Outbound: SIP over TLS on the Five9 SIP proxy.
  8. 8000-8015 UDP Outbound: Source ports the article lists for desktop RTP.
  9. 8080/8081 TCP Outbound: Network assessment at quality.five9.com.
  10. 8083 TCP Local: Five9 Softphone Service. The article says to keep other processes off it, and to open it on the host firewall when VDI needs it.
  11. 8843 TCP Outbound: HTTPS download of Five9 applications and API.
  12. 8880 TCP Outbound: HTTP download of Five9 applications.
  13. 443 TCP Outbound: Supervisor PC to WEM cloud, application access.
  14. 4443 TCP Outbound: Supervisor or admin workstation to the VO cloud for the Interaction Analytics UI.
