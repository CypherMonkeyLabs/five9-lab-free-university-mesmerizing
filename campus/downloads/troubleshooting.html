Troubleshooting tree

Five9 Lab study card. Numbers and names point at the sources. This is not a Five9 document.

  1. The DNIS does not answer. First check: Is the inbound campaign running, or only built?
  2. Callers land on a queue nobody staffed. First check: Open the Skill Transfer module.
  3. The agent hears silence, or the caller does. First check: Confirm signaling is up. A 200 OK does not prove RTP.
  4. Voice is live and the CRM pane is blank. First check: The adapter uses HTTPS and Secure WebSocket.
  5. The agent cannot paste a phone number. First check: Check whether the campaign is in TCPA manual touch.
  6. Customers hear a click and no agent. First check: Name the mode. Preview does not outdial. Predictive does.
  7. A test 911 call would send responders to the old HQ. First check: The address has to be the room the person is in.
  8. Standard reports are missing for a supervisor. First check: The user needs the reporting role and a reporting permission.
  9. The audio you need is gone. First check: Name which clock: audio, E911 recording, agent data, campaign state, the call log, or the DID.
  10. The IVA will not return the caller to a person. First check: Confirm the Studio region matches the task you copied.
