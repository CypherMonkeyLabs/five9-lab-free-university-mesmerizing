CRM

SDK and connectors when there is no adapter

Plus adapters, version lists that age, the SDK, and Salesforce inside the IVR.

Learn it in 5 minutes

HTMLMDPDFDOCX

CRM integrations · advanced · 12 min full read

The API product page lists a CRM SDK and web connectors beside the CTI, configuration, reporting, and statistics web services, plus Web2Campaign. The desktop page says bring your own CRM with the SDK.

  • Use the SDK or a connector on purpose
  • Own the retest

A connector is a lighter pop. An SDK integration is code. Neither is maintained as a managed package by the Salesforce story. You own the tests when Five9 or the CRM moves.

Scope the pop

Write what the connector will and will not do.

The scope is short.

  • SDK named? Yes.
  • Connectors named? Yes.
  • Who retests custom code? You.
  • URL pop scope? Smaller than a full adapter.
