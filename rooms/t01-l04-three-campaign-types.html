Foundations

Three campaign types

What a Five9 domain contains before anyone dials.

Learn it in 5 minutes

HTMLMDPDFDOCX

Foundations and the domain · foundation · 14 min full read

Public admin topics describe three campaign types: inbound, outbound, and autodial. Inbound answers a DNIS and runs the campaign IVR. Outbound uses the dialer and an agent. Autodial also dials a list, and the planning topic groups it with inbound when you add prompts and IVR.

  • Name the three campaign types
  • Explain blended without inventing a fourth type

Blended, on the product page, is agents moving between inbound and outbound. It is not a fourth campaign type in the planning roadmap. Do not create an object named Blended and expect the admin guide to define it.

Worked example

HTMLMDPDFDOCX

Pick the type

Match three requests to inbound, outbound, or autodial.

  1. A support number that must answer
  2. A list of renewals an agent should dial
  3. A reminder the IVR speaks before any agent

Each request has one type, and none of them is named Blended.

  • Three types? Inbound, outbound, autodial.
  • Stopped inbound? Busy signal.
  • What is blended? Agents working inbound and outbound, not a fourth type.
  • Autodial needs? List plus prompts and IVR, per the planning topic.
