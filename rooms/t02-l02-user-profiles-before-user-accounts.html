VCC admin

User profiles before user accounts

Clients, permissions, skills, prompts, DNC, and the PCs that drop calls.

Learn it in 5 minutes

HTML

VCC administration · foundation · 12 min full read

The planning roadmap says to define user profiles before you add user accounts. A profile is the permission bundle. An account is the person. Creating people first and hoping the default permissions match the job is how reporting and call-variable edits go missing.

  • Create a profile before accounts
  • Keep admin rights off the agent profile

Skill groups then take users who already have the agent or supervisor role. An administrator account is not automatically a member of a queue.

The two profiles are different.

  • Profile or account first? Profile, then account.
  • Who joins a skill? Agent or supervisor users.
  • Missing permission symptom? It looks like a missing feature.
  • Call variable edits? A named permission on the administrator role.
