Inbound

Schedules, not a stopped campaign

DNIS, run state, scripts, overflow, schedules, and the pause between calls.

Learn it in 5 minutes

HTMLMDPDFDOCX

Inbound campaigns · practice · 12 min full read

The campaign admin tree includes IVR script schedules for autodial and inbound campaigns. The planning topic tells you to set the campaign IVR schedule after the script exists. A schedule swaps treatment by time. Stopping the campaign does not. Stopping it returns busy.

  • Prefer a schedule to a stopped campaign
  • Keep state running

This lab does not reproduce the schedule dialog field by field. Use the schedule when you need a night path, and confirm the campaign stays running.

Write the night rule

One sentence that forbids stopping the campaign at close of business.

  1. Name the day script
  2. Name the night script
  3. State remains running

The sentence uses the word running.

  • When is the schedule set? After scripts exist.
  • Nightly stop? Causes busy, not a closed prompt.
  • Which types have the schedule topic? Autodial and inbound.
  • Campaign state at night? Running, with a different script.
