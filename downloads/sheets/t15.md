# From UCCX and UCCE

- There is no import button. Rebuild the domain, then move a number. There is no import button This track is a teaching bridge. Five9&#x27;s public pages name Cisco as a SIP gateway type. They do not publish a wizard that reads a UCCX script or a UCCE dial plan and emits a domain. CSQs, skills, and the partition you will not find In this teaching map, a UCCX contact service queue is closest to a Five9 skill group: the people who can take that work. A UCCE skill group is a similar idea with a different name. Precision queues and attributes do not have a one-field equivalent you should invent. Scripts are rebuilt in modules A UCCX script is a document in Cisco&#x27;s editor. A Five9 IVR script is a chain of modules from the IVR Administrator&#x27;s Guide: Menu, Get Digits, If/Else, Skill Transfer, Play, and the rest of that chapter. The lab&#x27;s builder speaks those names and exports a learning JSON that VCC will not import. Dialing modes do not survive the move by osmosis UCCE outbound has its own pacing words. Five9&#x27;s product pages talk about Preview, Progressive, Power, Predictive, and Manual Touch. The simulator in this lab is a classroom clock, not either vendor&#x27;s algorithm. Numbers, lists, and ANI are a data project DNIS values, calling lists, dispositions, and do-not-call entries are domain data. They are not inside the Cisco script file. A cutover that moves only the IVR still has nothing to dial and nowhere legal to send a call. The gateway cut, without pretending to be the CUBE guide When the third SIP story is a Cisco gateway, the technical requirements are still the Five9 side: DNS SRV preferred, G.711 as the default codec, TLS 1.2, no double NAT. What the gateway itself must rewrite — number format, a normalization script, early media — lives in Cisco&#x27;s documentation. Cutover morning is a checklist, not a mood The morning the numbers move, the domain should already contain skills, a script, a running inbound campaign, loaded lists, dispositions, DNC, an assigned profile, and a desktop the agent has signed into. E911 addresses have to be dispatchable for the place the agent actually is. A stale office address is not a courtesy.
