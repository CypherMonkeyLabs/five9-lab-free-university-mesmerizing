# Ecosystem

- Every box needs a link. Every word needs a page or a local label. The domain has neighbors A Five9 domain does not live alone. Voice arrives on a SIP story. Agents sit in a desktop. WEM or a partner workforce suite watches the roster. A CRM pops. GenAI Studio may draft a summary. E911 carries a location. Reports leave through a role and an API. Workforce, quality, and the recording shelf The WEM product page describes workforce management, quality, analytics, surveys, and recording, and it also describes a Verint partnership. Five9 says it manages install and upgrades for the solution it delivers. The data sheet is the short version of that claim. Analytics and the report that is not a dashboard rumor Analytics shows up on the WEM page and inside reporting. They are not one button. Standard reports need the Reporting role. Categories include ACD Queue, Campaign, Call Log, and the rest of that list. Layouts are tabular, summary, and matrix. AI agents are a handoff with a name Five9 Engage talks about self-service and the agent desktop together. Studio holds a digital IVA task. GenAI Studio is where knowledge and prompts are tested, and the product page says it powers Five9 AI applications, starting with Agent Assist summaries. This lab does not name a default model. CRM, UC, and the desktop are three contracts Plus adapters named in the technical requirements include Salesforce, ServiceNow, Dynamics 365, Zendesk, Oracle, NetSuite, Epic, and the Agent Desktop Toolkit. Zoom Phone and Teams show up as prebuilt paths on the API page. A UC app on the PC is also a bandwidth line, about 320 kbps. The glossary is the contract with yourself Teams lose hours to words that Five9 uses narrowly: domain, skill, campaign profile, DNIS, disposition, list penetration, vertical dialing, campaign, autodial, blended, manual touch. The ecosystem glossary in this lab defines the ones we could cite and marks the rest. Read the map before you add a box Integration maps fail when a logo is enough. Salesforce in the IVR is a module. Salesforce on the desktop is an adapter. Certified Caller is not the ANI. RedSky is not the ITSP. Verint is not automatically your WEM. Studio regions are not Equinix edges.
