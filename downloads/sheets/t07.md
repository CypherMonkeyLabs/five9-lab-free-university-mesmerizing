# IVR scripts

- Scripts are named modules. The builder speaks that vocabulary and does not pretend to export a VCC file. The module list is the vocabulary The IVR modules chapter names the blocks you may place. The list includes Play, Menu, Get Digits, Input, Voice Input, If/Else, Case, Set Variable, Lookup Contact Record, Query, Skill Transfer, IVA Transfer, Voicemail Transfer, Set DNC, Third Party Transfer, Foreign Script, Language, and others such as Conference, Iterator, and the Salesforce modules. Play, Menu, digits, and voice Play speaks a prompt or TTS. Menu takes a choice and has an exit per option. Get Digits and Input collect what the caller types. Voice Input and the Natural Language Processing module are the speech-side blocks in the same chapter. Input is what the ZIP-code web-service example uses, storing ZIP as a variable. If/Else is two ways. Case is more If/Else has two branches. The modules chapter includes both If/Else and Case. When you need three or more outcomes, Case is the block that exists for that. Nesting If/Else until the drawing looks like a hedge is how scripts become unreviewable. Skill Transfer has more than a skill name The community article lists General, Skills, Announcement, Priority, Connectors, Queue Callback, and Disposition. It also says &#x27;six tabs&#x27; and then names more than six. Count the tabs in your editor. Do not trust the word six. Variables, lookup, and query Set Variable writes a value. Lookup Contact Record reads the contact. Query calls out, and the published example is an XML web service POST whose response groups are mapped with regular expressions into variables. That example uses script variables, not call variables, because the caller is not connected to an agent. IVA, foreign scripts, DNC, and leaving the platform IVA Transfer hands the call to a Studio task. Foreign Script jumps to another IVR script. Set DNC is the removal action. Third Party Transfer leaves your agents. Language switches prompt language. These are five different exits. A diagram that says &#x27;send to bot&#x27; does not say which one. Visual IVR and frames The technical requirements say administrators can apply web page security so a Visual IVR script is not embedded in a frame where the user can be hijacked. The mechanism named is the X-Frame-Options header. The browser table in that PDF lists old versions and tells you to test others.
