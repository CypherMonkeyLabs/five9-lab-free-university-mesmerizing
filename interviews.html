What do you build before an outbound campaign?

Skill groups, user profiles, users, contact fields, lists, dispositions, and campaign profiles. Then the campaign.

Planning your implementation

Which builds add IVR scripts on the planning roadmap?

Inbound and autodial.

Planning your implementation

What is a Five9 domain?

The tenant boundary. Lists and skills do not leak into the next domain.

Planning your implementation

Does Five9 use CUCM partitions?

Not in the admin model this lab cites. The boundary is the domain. Mapping partitions to anything is a teaching bridge.

Skill groups

Who can be in a skill group?

Users with the agent or supervisor role. A user can be in more than one skill, and a campaign can have more than one skill.

Skill groups

How many campaign profiles can a campaign use at once?

One. A profile can still be reused by several campaigns. Assign it in Advanced mode.

Campaign profiles

What can a campaign profile override?

Defaults such as the ANI. Workflow rules can swap the profile.

Campaign profiles

What happens if an inbound campaign is stopped?

It does not answer. Callers can hear busy.

Inbound campaigns

Name the three campaign types.

Inbound, outbound, and autodial. Blended is how you staff, not a fourth type.

Outbound product page

What is list penetration?

The default walk: the first number on every record, then the next.

List dialing modes

What is vertical list dialing?

The dialer finishes the numbers on one record before it moves on.

List dialing modes

What does a final disposition do to the other numbers on a record?

It stops them for that campaign.

List dialing modes

Name the dialing modes on the product pages.

Preview, progressive, power, predictive, and manual touch.

Dialer product page

How does the outbound page describe progressive?

One customer call per available agent.

Outbound product page

Why will you not state a numeric abandon default?

The defaults page warns if Max Abandoned Call Percentage changes. It does not give this lab a percent worth repeating.

Default campaign settings

What abandon windows does the defaults page describe?

A US rolling 30 days and a UK window of 24 hours, set with a Five9 representative.

Default campaign settings

What does TCPA manual touch block?

Paste and drag. The agent types the external number. Dial enables when it matches. Preview timeout sets Not Ready and does not auto-dial.

TCPA manual touch

Which permission allows skipping records in TCPA manual touch?

User Can Skip Contact Records in TCPA Manual Touch.

TCPA manual touch

Name four IVR modules.

Play, Menu, If/Else, and Skill Transfer are in the modules chapter, among others.

IVR modules

Where does a Skill Transfer with no skill go?

The community article says the Default queue.

Skill Transfer functions

Are call variables historical?

No. Enable reporting before the calls you need. Apply to All Dispositions skips custom dispositions.

Call variables for reporting

Who can run standard reports?

A user with the Reporting role and at least one reporting permission.

Generating standard reports

Why is a matrix a bad CSV?

The reporting article treats matrix as a layout, not a direct CSV export.

Generating standard reports

How long is the call log, per the July 2026 article?

About 60 days unless retention is extended. Audio follows a different clock.

Call log filters

How long does the retention page keep VCC audio?

The sooner of 30 days, a successful SFTP or FTP offload, or the contract.

Data retention

How long are DIDs kept after a domain closes?

90 days. A disabled domain itself is 120 days after closure.

Data retention

Name two API families without guessing SOAP versus REST.

Reporting Web Services and Statistics Web Services. The overview also says REST. The transport per family stays unconfirmed here.

APIs and SDKs

What is the default codec?

G.711, described as uncompressed. DNS SRV is preferred for SIP targets.

Technical requirements PDF

Which TLS versions matter?

TLS 1.2 is required. TLS 1.1 is not supported. TLS 1.3 inbound ciphers are listed.

Technical requirements PDF

Is satellite a supported agent path?

No. Cellular and 5G are not supported either. One-way latency should stay under 150 ms.

Technical requirements PDF

What does the E911 data sheet say you dial?

911 directly, with no prefix, and a dispatchable location. The partner named is RedSky.

E911 data sheet

What does MyE911 history show an org admin?

Time, user, number, location, recording, and the SIP invite.

MyE911 call history

Is a campaign-profile ANI the same as Certified Caller?

No. Certified Caller is the STIR/SHAKEN program associated with FCC and CRTC.

Certified Caller

What is on the WEM product page?

Workforce management, quality, analytics, surveys, recording, and a Verint partnership.

Workforce engagement management
